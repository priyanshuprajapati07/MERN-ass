Design Choices

Colour: Deep blue represents trust and professionalism. Orange is used as an accent to make important buttons easy to notice.

Typography: The system font stack loads quickly, while a line-height of 1.6 helps keep paragraphs readable.

Layout: The content has a maximum width of 900px to improve readability. White cards stand out against the light background.

Maintainability: CSS custom properties store the main colors and border radius, making the design easier to update.

Responsive Design: Media queries adjust spacing and navigation for smaller screens.

Navigation: CSS :target displays the section selected from the navigation menu.
