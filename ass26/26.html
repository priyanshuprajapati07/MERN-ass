3. Box Model Calculation

By default, CSS uses box-sizing: content-box.

Content Width 200px
Padding 20 × 2 = 40px
Border 10 × 2 = 20px
Total Width 200 + 40 + 20 = 260px
Total Height 80 + 40 + 20 = 140px
Width Including Margins 260 + 30 × 2 = 320px
Height Including Margins 140 + 30 × 2 = 200px
Remember: Margin adds space outside the border. It is not included in the element's CSS width or height.

4. Using box-sizing: border-box

With box-sizing: border-box, the declared width includes the content, padding, and border.

For a width of 200px, padding of 20px on each side, and a border of 10px on each side:

Content width = 200 − 40 − 20 = 140px

The total width remains 200px, excluding margins.

Developer tip: Many developers use * { box-sizing: border-box; } to make element sizing easier to manage.
