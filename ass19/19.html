Why Are Meta Tags Important?

  • Charset: Specifies character encoding so symbols and text display correctly.
  • Viewport: Helps pages display correctly on mobile devices.
  • Description: Provides a summary that search engines may use in search results.
  • Author: Identifies the author of the page.
  • Robots: Provides instructions to search engine crawlers.
  • Open Graph: Provides information that social platforms can use when displaying shared links.
  • Theme Color: Suggests a color for certain browser interface elements.

Audit Checklist

Before marking a file as fixed, check that it contains:

  1. A valid character encoding declaration.
  2. A responsive viewport meta tag.
  3. A meaningful page title.
  4. A relevant meta description.
  5. Correct author information, if required.
