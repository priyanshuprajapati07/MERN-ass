CSS Selectors Summary

  • * — Universal selector
  • p — Element selector
  • .card — Class selector
  • #special — ID selector
  • h2, h3 — Grouping selector
  • .card a — Descendant selector
  • ul > li — Child selector
  • h2 + p — Adjacent sibling selector
  • input[type="text"] — Attribute selector
  • a:hover — Pseudo-class
  • p::first-line — Pseudo-element
