Responsive Audit Report

  • Viewport: Added the viewport meta tag.
  • Container: Used max-width and width: 100%.
  • Images: Images fit inside their cards.
  • Typography: Used clamp() for responsive headings.
  • Navigation: Links wrap on smaller screens.
  • Table: Added horizontal scrolling when needed.
  • Tap targets: Navigation links have at least 44px height.
  • Grid: Cards automatically adjust to available width.
Screen Expected behaviour How to verify
Desktop Multiple cards per row Check card alignment
Tablet Fewer cards per row Resize browser
Mobile Cards fit the screen Check navigation and images
Narrow screen Table scrolls inside its wrapper Check for page-wide overflow

Note: These are expected behaviours, not a record of tests already performed. Verify each screen size in your browser.
